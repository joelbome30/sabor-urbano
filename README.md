# Sabor Urbano

Landing page responsive para un restaurante de comida urbana, construida con HTML, CSS y JavaScript nativo.

## Ejecutar localmente

```bash
python3 -m http.server 4173
```

Después abre `http://localhost:4173`.

## Funcionalidades

- Menú filtrable y llamadas a la acción por WhatsApp.
- Animaciones de entrada, scroll y estados hover.
- Diseño responsive para escritorio y móvil.
- Fotografías optimizadas en WebP.
- Easter egg activado con `Alt + Ctrl + Shift + S` y un clic en Instagram.
